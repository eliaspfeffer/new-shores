# Construction atlas prompts

Built-in image generation, 12 September 2026. Original project art used as edit targets. The first generation returned a baked checkerboard; a second edit replaced only the background with magenta for runtime color-key import. Originals remain in the generation directory. No original-game sprites embedded.

## basic

Use case: precise-object-edit. Asset type: two-stage construction sprite atlas for an isometric strategy game. Input image: the project's OWN completed-building sprite atlas, edit target and strict identity reference. The source has 4 columns x 2 rows. First three cells are trees and rocks; leave those cells empty. Other cells: row1 col4 storage barn, row2 col1 woodcutter, col2 quarry yard, col3 house, col4 stone tower.
Produce a NEW transparent PNG atlas with exactly 4 columns and 4 equally sized rows. The top 2 rows correspond one-to-one to the source cells: FOUNDATION stage (excavated dirt, low stone footings following that EXACT building's footprint, no completed walls or roof). The bottom 2 rows correspond to the SAME source cells in the SAME order: HALF-BUILT stage (unfinished masonry and timber structural frame, visible interior work floor, missing roof, mine openings supported by half-assembled beams, masonry partly laid, unfinished wheel supports). Buildings are under construction, not ruined: tidy new work, no vegetation grown over the building, no damage.
Every individual cell has identical SQUARE bounds, transparent margins 8%, the ground baseline at 88% cell height; buildings must maintain the reference's exact footprint, camera angle, facing, relative scale, architectural identity and warm painted textured rendering. Foundations stay LOW in their cells, not enlarged to fill their square. Half-built roofs mostly absent; no inhabitants, no floating plank bars, no opaque background, NO checkerboard baked into pixels, no labels, no grid lines, no arrows, no finished buildings. Genuine alpha transparency. The final stage remains the existing supplied image, so these must line up with it. Use 2048x2048 square composition.

### Background correction

Use case: background-extraction. Edit the supplied construction sprite atlas. Change ONLY every gray/white checkerboard background pixel (including holes through wooden frames) to absolutely uniform opaque pure magenta RGB 255,0,255 (#FF00FF). This is a game color-key atlas. Preserve ALL buildings, their placement, exact number, scale, framing, colors and every construction stage. Do not add tiles or relocate or rescale anything. NO checkerboard, NO gray, NO gradient in the background, NO shadows on the background. Plain solid magenta background all the way to each sprite edge. Keep the exact source image dimensions and sprite layout.
